# SSA 0.30.0 - Mockup UI Refresh

## UI changes
- Reworked tablet UI to better match the user's classic gray/blue mock-up.
- Main menu now uses a radial / bubble-style layout with a central SSA hub.
- Hangar, Jetway, Parking, Settings, and Developer pages now use simpler stacked button layouts closer to the reference mock-up.

## Animation changes
- Added a short opening animation when the tablet is shown.
- Added button bubble / pulse feedback when major buttons are clicked.

## Notes
- Existing SSA systems remain connected to the same hangar / jetway / parking / developer actions.
- This update is focused on presentation and interaction polish.
