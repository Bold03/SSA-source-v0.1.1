# SSA 0.27.0

- Developer tab is hidden while Developer Mode is OFF.
- Developer Mode is enabled/disabled from Settings or the existing SSA developer command.
- Reworked Hangar page into an airport-style schematic map.
- Nearby SSA hangars are rendered as clickable H1/H2/... points around the aircraft position.
- Clicking a hangar point toggles that hangar and selects it.
- Selected hangar status is shown at the lower-left of the map (OPENING / OPEN / CLOSING / CLOSED + progress).
- Removed Announcement UI, announcement runtime, OpenAL dependency, and announcement example configuration.
- Home dashboard now focuses on Hangar, Jetway, VDGS, Ground Traffic, and Developer tools.
